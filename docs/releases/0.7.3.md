# 0.7.3 发行说明

引擎 `ppvpn-core`、账号 `ppvpn-account`、命令行 `ppvpn`、桌面客户端和特权服务都是 0.7.3。

## 主要变化

- **服务地址改为 `www.peakpass.dev`（#517）。** 登录页也在这个域名下打开。旧地址照常可用，已登录的用户不受影响。
- **网络诊断（#526）。** 桌面版在“设置 › 高级”、手机版在“我 › 支持”里新增“网络诊断”：检查服务和节点的域名能否解析、能否建立 TCP 和 TLS 连接，并对照国内两家 DoH（阿里、DNSPod）的解析结果，判断 DNS 是否被篡改；结果可以复制下来附到工单里。连接服务失败时，客户端会自动做一次只用系统 DNS 和 TLS 的检查（不查 DoH），结果写进日志，最多每 10 分钟一次。命令行：`ppvpn doctor --network`。
- **iOS：TestFlight 版打开后白屏的问题已修复（#529）。** 打包时不再裁掉引擎对外的函数；发布流程在上传前检查这一点。
- **正式版去掉“设置 › 高级”里的“API 地址覆盖”（#520）。** 只有调试版还有；以前保存过的值不删除，但正式版不再使用。

## 升级注意

- 从 0.7.x 或 0.6.x 升级都会保留登录、设置、所选节点和消息，不需要重新登录。
- macOS 和 Windows 通过应用内更新收到 0.7.3；Linux 用 apt 或 dnf 升级。
