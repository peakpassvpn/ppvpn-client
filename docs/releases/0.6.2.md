# 0.6.2 发行说明

## macOS 安装

- **首次安装改用 .pkg 安装包。** 官网的 macOS 下载按钮给 `PPVPN-<版本>-macos-<架构>.pkg`：打开时系统拦截一次，到「系统设置 → 隐私与安全性」点「仍要打开」，安装器把 PPVPN 装进「应用程序」。装好的应用打开时不再提示，也不会被系统移到临时位置运行。以前用 DMG 安装要放行两次（DMG 一次、应用一次）。
  - 安装包只装 `/Applications/PPVPN.app`，安装后把它交给当前登录的用户，和拖进去安装的一样，之后的自动更新不需要管理员密码。
  - DMG 仍在 GitHub Release 里，想手动安装的可以照旧在访达里把应用拖进「应用程序」。自动更新仍用 DMG。
- **特权服务按签名认应用。** 系统服务以前只接受 `/Applications/PPVPN.app` 这个路径上的应用，现在核对的是应用的代码签名（钉在我们的签名证书上），被系统移位运行的同一份应用也能连接。安装和卸载服务时，以管理员身份运行的程序也先核对签名，包里的文件被改过就拒绝。
- **自动更新时推送助手不再被系统强行结束。** 安装更新前应用先注销推送助手，新版本启动后马上重新注册。从 0.6.2 起往后的更新生效；从 0.6.1 更新到 0.6.2 时还会出现一次约 1 分钟的推送中断。

## 升级注意

- **macOS：升级后第一次用增强模式连接时，会要一次管理员密码。** 0.6.2 的特权服务和 0.6.1 的不同，连接前客户端会替换它。
