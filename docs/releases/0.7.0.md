# 0.7.0 发行说明

引擎 `ppvpn-core`、账号 `ppvpn-account`、命令行 `ppvpn`、桌面客户端和特权服务都是 0.7.0。

## 主要变化

- **桌面客户端换成新界面（#401）。** macOS、Windows、Linux 三端用同一套界面，原生版不再发布。
  - 包含连接、节点、增强模式、消息中心、日志、设置、托盘菜单、开机自启和推送通知。
  - 安装包、安装位置、更新源和签名都和原生版相同，已安装的用户原地升级。
- **增强模式不再周期性断线（#438）。**
  - 健康检查偶尔失败一次不再重连：先复查，下一轮仍失败才恢复；流量泄漏类问题仍立即恢复。
  - 只是暂时连不上 PPVPN 服务器、隧道本身正常时，保持连接并提示，按退避自动复查，不再重启核心。
  - "被占用"的提示改为说明实际原因（这台电脑上的另一个会话或系统用户、其他软件接管了网络或路由），不再误报"另一台设备"。
- **新界面的验收修复（#401）。** 设置页操作开机自启时闪退；应用内图标、通知位置、线路名、代理信息展示、空间切换入口和过渡动画。
- **依赖安全检查（#422）。** CI 新增依赖漏洞和来源检查；rustls、rustls-webpki 和根证书随之升级，日志库去掉了不用的 YAML 依赖；tokio 升到 1.53.3（RUSTSEC-2026-0386）。

## 升级注意

- 从 0.6.x 升级会保留登录、设置、所选节点和消息，不需要重新登录。
- macOS 和 Windows 通过应用内更新收到 0.7.0；Linux 用 apt 或 dnf 升级。
- 需要退回时，直接安装 0.6.4 即可，数据两个版本通用。
