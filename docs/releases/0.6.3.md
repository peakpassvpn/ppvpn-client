# 0.6.3 发行说明

引擎 `ppvpn-core`、账号 `ppvpn-account`、命令行 `ppvpn`、桌面客户端和特权服务都是 0.6.3。

## 主要变化

- **休眠和唤醒交给系统通知（#375）。** 桌面端三个平台在系统休眠、唤醒时通知内核：macOS 用 NSWorkspace 的休眠和唤醒通知，Windows 用 `PowerRegisterSuspendResumeNotification`，Linux 用 logind 的 `PrepareForSleep`。标准模式和增强模式的内核都会收到。
  - 休眠期间，内核的定时检查和规则集更新暂停。
  - 唤醒时，休眠不到 2 分钟就什么都不断开；2 分钟以上只断开闲置的连接，各线路重新测速，正在用的连接保留。以前每次唤醒都会重置所有连接。
  - 如果漏掉了唤醒通知（例如应用中途退出），内核在系统醒来约 1 分钟后自己恢复。
  - 自行承载引擎的宿主可以调用新的 `Engine::sleep` / `Engine::wake`（Core API `/v1/sleep`、`/v1/wake`），这是可选的，见 [宿主接入](../host-integration.md) 4.7 节。命令行不调用它们。
- **节点名更长。** 后端的节点名改成"地区 + 线路类型 + 出口 IP"，例如 `🇺🇸洛杉矶家宽 203.0.113.10`；一个出口有多个入口时再加上入口名。
  - 桌面端三个平台的节点列表和概览里，名字保持一行，放不下时截断，鼠标悬停显示全名。
  - 选中的节点、线路固定和本地代理用户名都按节点 ID 记，改名后不受影响。
  - 命令行 `ppvpn nodes` 照旧完整打印名字。
- **Sail 升到 0.20.0。** 其中包括：AnyTLS/smux 会话的边界检查（安全修复）；不再承载数据的多路复用会话在写超时后结束；Windows 的 TUN 不再在启动后不久把 IPv4 地址换成链路本地地址。

## 升级注意

- **macOS：升级后第一次用增强模式连接时，会要一次管理员密码。** 0.6.3 的特权服务和 0.6.2 的不同，连接前客户端会替换它。在这个提示里点取消，这次仍用旧服务连接；重启应用后会再问。只用标准模式时不会提示。
- Windows 的服务由安装程序替换，Linux 的由软件包替换，都不需要额外操作。
