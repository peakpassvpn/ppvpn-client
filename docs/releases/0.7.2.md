# 0.7.2 发行说明

引擎 `ppvpn-core`、账号 `ppvpn-account`、命令行 `ppvpn`、桌面客户端和特权服务都是 0.7.2。

## 主要变化

- **macOS：应用、安装包、DMG 和命令行都用 Developer ID 签名并经过苹果公证（#472）。** 首次打开不再需要到系统设置里手动放行。
- **Windows：安装包和程序用 Azure Artifact Signing 签名（#490）。** 更新时核对发布者身份。
- **账号接口走系统代理（#477）。** 与原生版相同：设置了系统代理的电脑，登录和刷新也经过它。
- **Windows：升级和卸载更稳（#474、#503）。** 文件被占用时卸载会重试删除；升级前会指出占用已安装文件的进程。
- **Windows：登录页改用系统方式打开浏览器（#501）。**
- **登录页在窗口较矮时可以滚动（#495）。**
- **客户端报告的版本号取自构建时的版本（#502）。**

## 升级注意

- 从 0.7.1、0.7.0 或 0.6.x 升级都会保留登录、设置、所选节点和消息，不需要重新登录。
- macOS 和 Windows 通过应用内更新收到 0.7.2；Linux 用 apt 或 dnf 升级。
