# 0.7.6 发行说明

引擎 `ppvpn-core`、账号 `ppvpn-account`、命令行 `ppvpn`、桌面客户端和特权服务都是 0.7.6。

## 主要变化

- **应用内更新与静默安装防护（#619、#646、#654、#658）。** 全屏使用其它应用时推迟弹出更新提示，升级完成通知不再重复弹出；特权服务安装更新期间阻止启动新连接并严格校验安装包辅助程序路径与签名；静默更新与 Linux 更新源检查均增加响应超时保护。
- **连接、路由切换与系统代理稳定性（#573、#648、#649、#650、#652、#655、#657、#658）。** 切换路由模式失败时回滚到原模式并保留当前连接；本机代理端口迁移时保留系统代理归属；后台健康检查与自愈不再覆盖用户刚切换的节点或配置；在线更新节点后即时刷新本地代理端口列表；特权服务 IPC 请求超时后主动关闭失效通道；规则集更新先经校验激活再写入重启缓存，并按稳定顺序规范化 TUN 排除路由。
- **增强模式故障说明与登录前网络诊断恢复（#657）。** 增强模式启动失败时按阶段给出明确原因与处理建议，支持一键复制脱敏诊断摘要；未登录页即可运行网络诊断，确认系统 DNS 异常且备用解析通过原始服务域名证书校验后，当前会话自动启用备用解析恢复连接。
- **账号、团队与消息状态隔离（#647、#653、#658）。** 退出登录先清除本机凭据再通知服务端注销；切换账号立即清空旧团队缓存；未通过校验的配置不再覆盖已有配置来源记录；消息标记已读失败回滚时保留已加载分页与后续操作。
- **移动端连接清理、界面适配与隧道稳定性（#570、#571、#574、#582、#591、#658）。** 手机连接中途失败时自动停止已拉起的系统隧道；节点刷新后自动清理失效的地区筛选并优化窄屏与大字号排版；修复 iOS 隧道数据目录对齐与过期 DNS 会话回收，并适配 iOS 原生导航栏外观。

## 升级注意

- 从 0.7.x 或 0.6.x 升级都会保留登录、设置、所选节点和消息，不需要重新登录。
- macOS 和 Windows 通过应用内更新收到 0.7.6；Linux 用 apt 或 dnf 升级。
