# 0.6.4 发行说明

引擎 `ppvpn-core`、账号 `ppvpn-account`、命令行 `ppvpn`、桌面客户端和特权服务都是 0.6.4。

## 主要变化

- **Sail 升到 0.21.0（#386）。**
  - 修复：增强模式下，一端先关闭的 TCP 连接可能丢掉最后一段数据。这个问题从 Sail 0.15.0 起就存在。
  - Linux 的 TUN 改为单队列。桌面端的吞吐受出站连接限制，不受 TUN 队列数影响。
  - 引擎的配置和嵌入接口没有变化。

## 升级注意

- **macOS：升级后第一次用增强模式连接时，会要一次管理员密码。** 0.6.4 的特权服务和 0.6.3 的不同，连接前客户端会替换它。在这个提示里点取消，这次仍用旧服务连接；重启应用后会再问。只用标准模式时不会提示。
- Windows 的服务由安装程序替换，Linux 的由软件包替换，都不需要额外操作。
