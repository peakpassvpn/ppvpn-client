# 0.7.4 发行说明

引擎 `ppvpn-core`、账号 `ppvpn-account`、命令行 `ppvpn`、桌面客户端和特权服务都是 0.7.4。

## 主要变化

- **修复开启增强模式后无法上网（#536）。** 以前兼容模式异常退出后，系统代理可能一直指向本机 7891 端口，而这个端口已经没有程序在监听。现在客户端启动、连接和恢复系统代理时，都会关掉这类失效的代理设置。其他软件设置的代理不受影响。
- **修复兼容模式下速度忽高忽低、偶尔连不上服务（#545）。** macOS 默认只允许一个应用同时打开 256 个文件和连接。连接一多（例如测速时），新连接就建不起来。现在引擎启动时会把这个上限调高（最多 65536），在 macOS 和 Linux 上都生效。
- **修复切换模式时一直显示"正在断开"（#543）。** 特权服务拒绝客户端时（例如 App 不在"应用程序"文件夹里运行），客户端现在会直接视为已断开，不再反复等待服务确认。
- **配置有问题时说清原因，并继续使用上一份可用的配置（#532）。** 服务端下发的配置被引擎拒绝时，概览页会显示是配置的问题，日志会写明错误码和出错的字段。客户端会保存最近一份可用的配置，重启后，或者暂时连不上服务时，都会继续使用它。退出登录、切换账号或团队时，这份配置会被删除。
- **连不上服务时，日志记录完整原因（#537）。** 便于排查"网络不可达"类问题。客户端还会更早关闭长时间空闲的连接，避免下次请求复用已经失效的连接。

## 升级注意

- 从 0.7.x 或 0.6.x 升级都会保留登录、设置、所选节点和消息，不需要重新登录。
- macOS 和 Windows 通过应用内更新收到 0.7.4；Linux 用 apt 或 dnf 升级。
- 服务地址仍是 `www.peakpass.dev`。
