# 0.7.1 发行说明

引擎 `ppvpn-core`、账号 `ppvpn-account`、命令行 `ppvpn`、桌面客户端和特权服务都是 0.7.1。

## 主要变化

- **Windows：没有装 VC++ 运行库的电脑也能安装（#465）。** 之前在这类电脑上，安装到“网络服务”一步会报错码 -1073741515 并停止。现在安装包自带所需的 VC++ 运行库，不用另装；打包时还会检查每个程序依赖的 DLL 都在安装包里或者是 Windows 自带的。
- **macOS：登录时启动改用 Swift 调用系统接口（#463）。** 实现与原生版相同，用法不变。
- **应用内更新的提示更简洁（#462）。** 更新窗口不再嵌入整个 GitHub 发布页面。
- **代理核心升级到 Sail 0.22.0（#421）。**

## 升级注意

- 从 0.7.0 或 0.6.x 升级都会保留登录、设置、所选节点和消息，不需要重新登录。
- macOS 和 Windows 通过应用内更新收到 0.7.1；Linux 用 apt 或 dnf 升级。
