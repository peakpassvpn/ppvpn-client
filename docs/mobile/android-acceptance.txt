Android mobile scope and acceptance — 2026-11-07

Implemented in shared mobile candidate
  target_os=android selects NoAppEngine; engine.rs is excluded from the App.
  PHONE sync never applies a Standard profile; tunnel host remains owner.
  App local proxy queries return empty and phone/tablet proxy UI is hidden.
  Running probes and selected-node latency use the tunnel transport.
  Desktop targets retain EngineLauncher and Standard behavior.

Native lifecycle implementation
  runner/android/.../TunnelService.kt:
    API26+ startForegroundService and immediate ongoing notification; API34+
    systemExempted foreground type/permission. Startup refusal fails closed.
    Serialized worker owns teardown without blocking onDestroy on main.
    Instance ownership prevents duplicate cleanup stopping a newer host;
    generation fences ignore old native exits. Closing NetworkWatch joins
    current delivery and blocks all later physical-network publication.
  runner/android/.../tunnel/TunnelHost.kt:
    per-host Listener.protect(fd), onExit and networkChanged contract remains.
  crates/tunnel-host/src/android.rs:
    Per-start owned Listener replaces the process-global listener slot.
    Rejected startup cannot replace the active listener; callback lifetime
    is drained by native stop. Protect still reaches VpnService.protect
    before core sockets dial.
  No replacement of Android FCM/self-hosted push behavior was attempted.
